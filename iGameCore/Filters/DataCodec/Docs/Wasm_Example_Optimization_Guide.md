# 浏览器示例（Examples/Wasm）性能优化

本文介绍 `../../../../Examples/Wasm` 浏览器示例工程自身的性能优化（页面加载、渲染数据与复用体系）。DataCodec 核心为浏览器环境做的适配见 `Feature_Guide.md` 第 4 章。

## 1. 对比概览

旧版浏览器示例（stable-sdk 时期、基于 MeshCodec 的 `../../../../Examples/Wasm`，即 main 分支版本）与新版（DataCodec）的主要差异：

| 环节 | 旧版（MeshCodec 时代） | 新版（DataCodec） |
| --- | --- | --- |
| 文件读取 | 整文件读为 ArrayBuffer 后整体复制进 Wasm 内存 | 字节范围随机访问，只读取所需字节区间 |
| 文件身份识别 | 无（无法在解码前确认文件身份） | 读取文件头少量字节即可获得包身份与源身份 |
| 首帧内容 | 必须完整解码全部几何、属性、拓扑 | 只恢复几何、连接关系与可见表面，属性按需读取 |
| 表面生成 | 解码完成后在常规对象上二次遍历提取 | 拓扑解码期间同步生成表面，块内消重 |
| 数据复用 | 无 | 同页模型复用、跨页面共享、浏览器持久缓存 |
| 解码执行 | 同步阻塞 | 后台任务 + 进度查询 |
| 内存适配 | 无显式约束 | 4 GiB / 16 GiB 两种地址空间规格，硬约束兜底 |

## 2. 文件加载优化

- **字节范围随机访问**：文件不再整体读入一块连续内存，而是由解码器按需请求字节区间（数据目录、目标帧、目标属性所在范围），页面只针对这些区间执行文件切片读取。未请求的字节始终留在文件与系统缓存中，I/O 总量与当前可见内容成正比，与文件总大小无关，首帧加载时间不随文件体积线性增长；
- **文件头预读与身份识别**：解码开始前仅读取文件最前端的少量字节，解析出压缩包身份与源身份，它既是资源分配与缓存索引的键，也是「重复打开同一文件时复用模型/表面」的判定依据，避免"必须先解码完才能确认是什么文件"的循环依赖；
- **按需属性与延迟恢复**：属性目录随首帧一并解析，但属性值延迟恢复：首次选择某个属性时才读取其对应的字节区间并完成解压，该属性随后驻留内存，再次切换不再产生文件 I/O；未被选择的属性在目录中始终可枚举、可补读；
- **后台解码与进度**：解码在独立工作线程中执行，主线程全程保持响应；页面通过进度查询获取阶段、进度、耗时与错误信息，可随时取消任务并触发统一的资源清理；
- **大文件分段暂存**：超大文件超过阈值后不再一次拷入线性内存，而是借助文件系统抽象层按固定分块大小分段写入暂存文件、逐段读取解码。分块大小受单次内存拷贝与 32 位内存视图的寻址上限约束，规避一次性超大拷贝造成的峰值内存与地址空间溢出。

## 3. 渲染数据优化

- **解码期同步生成表面**：首帧目标聚焦于可见外表面。拓扑块解码期间同步生成候选面与点映射，候选面在块内完成去重（局部哈希），各块结果在阶段末尾合并为全局表面。完整体拓扑无需先提交给常规对象、再整体遍历提取一次外表面，省去一次完整遍历与中间对象驻留；
- **延迟非必要工作**：首帧显示不依赖的派生数据（如线框索引）推迟到真正需要时再惰性生成，解码阶段的 CPU 时间优先供给首帧画面；
- **渲染数据直达**：一次解码任务同时交付几何、表面与解码会话，页面直接以已生成的表面结果建立绘制对象与颜色映射，中间不经过完整模型的二次拷贝或格式转换；
- **着色切换免重读**：首次属性加载完成后模型保持显示，之后切换着色字段（含切换范围模式）只需重算颜色映射与着色状态，不再重复读取已经驻留的文件字节。

## 4. 缓存与复用体系

浏览器端围绕「已解码内容」建立多层复用，避免重复解码：

| 层级 | 机制 | 用途 |
| --- | --- | --- |
| 解码帧缓存 | 以源身份为索引键的完整解码结果缓存 | 同一页面重复打开同一文件直接命中 |
| 同页模型复用 | 页面内模型注册表按源身份查重 | 重复导入同一文件时复用已加载模型 |
| 跨页面共享 | 共享工作线程托管表面绘制数据（顶点、三角面、边界标记），带租约与容量淘汰 | 多个标签页共用同一份表面，避免重复解码 |
| 浏览器持久缓存 | 文件系统访问 API 目录缓存表面数据，带版本与容量淘汰 | 刷新/重开浏览器后快速恢复表面显示 |

各层缓存独立失效：解码帧缓存与模型注册表以源身份为键、生命周期随页面；跨页面共享靠租约与淘汰策略控制容量；持久缓存带版本号，存储格式升级后自动作废重建。

表面数据是「纯绘制数据」，体积远小于完整模型；快速恢复表面显示后，完整体数据与首次属性仍由完整解码会话按需提供。冷加载基准测试会关闭上述全部复用路径，只反映真实的单帧首次加载。
