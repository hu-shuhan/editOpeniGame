# MergeVectorComponents（合并标量数组为向量）使用说明

## 功能

将用户指定的 3 个标量数组（顺序即 X/Y/Z 分量顺序）合并为一个多分量向量数组（`type=IG_VECTOR`，`dimension=3`），并输出为一个**独立的新节点**（输入网格的副本 + 合并向量）。原模型不做任何修改。

- 数据归属可选：点数据（`IG_POINT`）/ 面数据（`IG_CELL`），输出挂在同一归属上
- 3 个分量允许重复选择同一个标量
- 输出节点命名：`<向量名>_<模型名>_merged`
- 原标量数组保留不删除

## 输入 / 输出

| 项 | 说明 |
|---|---|
| 输入 | 1 个网格模型（DataObject，需含 AttributeSet）+ 3 个单分量标量数组名 + 数据归属 + 输出向量名（`默认为vector`） |
| 校验 | 每个名字必须存在于指定归属、类型为标量（`IG_SCALAR`）、单分量（`dimension==1`）、元素数一致 |
| 输出 | 独立输出节点（同拓扑网格副本），属性集中新增 `IG_VECTOR` 数组；原模型属性不变 |

## 调用方式——Qt 界面

菜单 `算法处理 → 合并标量数组为向量(merge_vector_components)`，左侧工具面板中：

1. 选择数据类型（点数据 / 面数据），X/Y/Z 候选随之刷新
2. 分别为 X / Y / Z 选择分量（不预选，允许重复）
3. 输出向量名默认 `vector`，可修改
4. 点击执行：模型树新增输出节点并自动选中合并向量，可在标量面板选择**模长**或**分量**着色

## 使用示例

### 命令行测试（自动运行，无需手动输入）

测试程序写死相对模型路径，构建后直接运行即自动完成点/面两组合并并逐项断言：

```
cmake --build <build-dir> --target testMergeVectorComponents
cd <build-dir>
./testMergeVectorComponents.exe        # 0=全部通过, 1=存在失败项
```

测试模型（`Examples/Models`，ASCII VTK，可手工编辑）：

- `MergeVectorComponents_Quad_Plane.vtk`：5x5 四边形面片，点标量 `u1/v1/w1`（dim=1）+ `vel`（dim=3，用于验证多分量过滤）+ 面标量 `c_amp`
- `MergeVectorComponents_Tri_Plane.vtk`：4x4 三角形面片，点标量 `a1/b1/c1`（dim=1）+ 面标量 `t_val`


## 注意事项

1. **查找按“名字 + 归属”精确匹配**：点/面数据存在同名标量时互不干扰，按所选归属取对应数组。
2. **输出节点为输入网格的深拷贝**（独立节点）；重复执行会生成新的输出节点，原模型与已有节点不受影响。
3. 同归属下与输出向量同名的旧属性会被新结果替换；不同归属的同名向量互不影响。
4. 输出数组类型：分量类型一致时保持原类型，混合类型提升为 `DoubleArray`。
5. 仅支持网格类输入（非结构网格 / 面 / 体网格）；其它数据类型会返回失败并给出提示。
